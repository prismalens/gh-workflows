What a manifest declares
Name and version · round types it can run · the verdict strings it posts and their mapping onto reviewed / threads-only / not-reviewed / blocked · which ingest fields it fills (a lane that reports no subagent_stats simply loses the fan-out panel, nothing breaks).
Comparing agents vision
Two agents on one repo render side-by-side on Health, split by agent the way rounds split by model today. Quality comparison stays on the three trusted finding fates; no cross-agent acceptance leaderboards.
Auth boundary
Read: Cloudflare Access, every viewer a policy principal. Ingest: bearer token per tenant. Multi-tenant open source replaces Access with product sessions; the Worker keeps validating its own JWTs.

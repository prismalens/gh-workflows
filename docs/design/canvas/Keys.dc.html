Billing mode changes the dashboard
Seat keys: cost stays the demoted list-rate column, never a tile.
Metered keys: spend is the bill; the overview gains a month-to-date tile scoped to metered rounds ("excludes 41 rounds on seats").
Alert, never block: only the provider's dashboard can enforce a cap, so we link there. Modes are never summed together.

The lane contract, assayer/v1. The registry validates and displays it; the contract check is a dry-run dispatch that proves the POST shape without reviewing anything.
1 · accept the standard workflow_call inputs: PR context, resolved config JSON, the name of the secret to read (never the value)
2 · post inline comments and a summary comment on the PR
3 · upsert the liveness comment with one of the eight verdict strings, verbatim grammar
4 · POST a usage record per round: session_id, repository, pr_number, head_sha, round_type, verdict_kind, duration_ms, agent_id, contract_version required; tokens, cost, turns, denials optional (unreported renders as "not reported by this agent", never zero)

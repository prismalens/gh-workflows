Create the GitHub App

Assayer uses one GitHub App per install. It is how people sign in, how roles derive from real repository permissions, how config edits open pull requests, and how PR titles reach the dashboard. The button below uses GitHub's manifest flow: the app is created pre-configured and its credentials land back here as Worker secrets. Assayer never sees your model keys; those stay in GitHub Actions secrets.

contents: read/writeopens config PRs against .github/claude-review.yml; nothing merges without a human
pull_requests: readPR titles and authors on the PR detail page, findings sweep later
members: readderives dashboard roles from org roles and repo permissions, cached 15 minutes
Create app on github.com
Provisioning from code instead? Set ASSAYER_INIT_GITHUB_APP_ID, ASSAYER_INIT_ORG and ASSAYER_INIT_INGEST_TOKEN as Worker secrets and this wizard skips itself.
